# SSKH 03 · 数据与接口

> 共享 DDL 规范见 [../../docs/02](../../docs/02-统一数据模型与DDL.md)，接口契约见
> [../../docs/03](../../docs/03-统一接口契约与错误码.md)。本文只写标准版落地。

## 1. 数据表（23 张 = 简易版 11 张 + 库语义 12 张）

### 1.1 核心表（与简易版**逐字节一致的 DDL**）

`app_meta` · `category` · `skill` · `skill_file` · `skill_version` · `risk_audit` ·
`risk_signal` · `contributor` · `contribution` · `doc_page` · `op_log`

### 1.2 标准版新增（12 张）

| 表 | 行数量级 | 说明 |
| --- | --- | --- |
| `skillset` | 2 | 逻辑库；`default` 内置不可删 |
| `ms_index_def` | 4+ | 索引定义（含状态机与命中统计） |
| `ms_index_entry` | 375×索引数 | **真实索引条目**（可查询、可证明） |
| `ms_constraint_def` | 5+ | 约束定义（7 类、ENFORCED/WARN） |
| `ms_event_def` | 3+ | 事件定义（触发时机 + 条件 + 动作） |
| `event_log` | 0+ | 事件派发日志（PENDING/DONE/FAILED/DEAD） |
| `ms_tx_log` | 每次写一条 | 事务台账：裁决 / 约束命中 / 索引 / 事件 |
| `agent_registry` | 2+ | Agent 注册（Key 支持 `env:NAME`） |
| `mcp_registry` | 2+ | MCP 注册 |
| `eval_metric_def` | 9 | 指标字典（与 `EvalService.SPECS` 同源） |
| `eval_run` | 0+ | 单点实测记录（含推理过程） |
| `eval_score` | 9×run | 单次运行的指标分（列名 `metric_value`，见下） |

> ⚠️ **`metric_value` 而不是 `value`**：`VALUE` 在 H2 里是保留字，
> 建表会直接语法错误（实测报 `expected "identifier"`）。这是方言子集的一个必须记住的坑。

## 2. 接口清单（标准版 40 项用例覆盖的端点）

### 2.1 沿用简易版（26 个，行为一致）

见 [../../NS-EasySkillHub/docs/03-数据与接口.md](../../NS-EasySkillHub/docs/03-数据与接口.md) §2。

### 2.2 库语义（`/api/v1/ms/**`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/ms/schema` | 元数据总览：6 张表 + 5 个概念 + 各类对象计数 |
| GET | `/ms/concepts` | 术语小词典（页面「库管理」顶部） |
| GET | `/ms/tables` | 查询台可用的表与列（白名单） |
| GET | `/ms/skillsets` | 逻辑库列表（实时算 `skill_count`） |
| POST | `/ms/skillsets` | 新建（admin） |
| DELETE | `/ms/skillsets/{code}` | 删除；非空 → 422/2000（admin） |
| GET | `/ms/indexes` | 索引列表 |
| POST | `/ms/indexes` | 新建并立即重建（admin） |
| POST | `/ms/indexes/{code}/rebuild` | 重建（admin） |
| GET | `/ms/indexes/{code}/entries` | 查看真实条目 |
| DELETE | `/ms/indexes/{code}` | 置 `DROPPED`（admin） |
| GET | `/ms/constraints` | 约束列表 |
| POST | `/ms/constraints` / PUT `/{code}` | 保存（admin） |
| DELETE | `/ms/constraints/{code}` | 删除（admin） |
| POST | `/ms/constraints/validate` | 全库校验（只报告，不写库） |
| GET | `/ms/events` | 事件列表 |
| POST | `/ms/events` / PUT `/{code}` / DELETE | 事件维护（admin） |
| GET | `/ms/events/logs` | 派发日志（可按 status 筛） |
| POST | `/ms/events/logs/{id}/retry` | 重试死信（admin） |
| GET | `/ms/tx-log` | 事务台账（可按 skill_id 筛） |
| POST | `/ms/query` | 查询台执行 |
| POST | `/ms/query/plan` | 查询计划（不执行） |

### 2.3 实测与接入

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/eval/runs` | 单点实测（同步返回） |
| GET | `/eval/runs` / `/eval/runs/{code}` | 列表 / 详情 |
| GET | `/eval/metrics` | 9 条指标字典（两维） |
| GET | `/eval/summary?skill_id=` | 质量汇总（均值、最好/最差、指标均值、TOPSIS 排名） |
| GET | `/eval/ranking` | 全部有实测记录的 Skill 排名 |
| GET/POST/PUT/DELETE | `/agents` `/agents/{code}` | Agent 注册表 |
| POST | `/agents/{code}/probe` | 探活 |
| GET/POST/PUT/DELETE | `/mcp` `/mcp/{code}` | MCP 注册表 |
| POST | `/mcp/{code}/probe` | 探活 |
| GET/POST | `/conn/doctor` | 一键体检（出网 + 每个 Agent/MCP） |

## 3. 错误码（标准版新增）

| code | 常量 | HTTP | 触发场景 |
| ---: | --- | ---: | --- |
| 2000 | `MS_CONSTRAINT_VIOLATION` | 422 | 违反 ENFORCED 约束；删除非空逻辑库 |
| 2003 | `MS_EVENT_DEAD` | 409 | 事件进入死信（重试 3 次仍失败） |
| 2100 | `QUERY_REJECTED` | 409 | 查询台语句非法（带"第几个词 + 可用列"） |
| 3001 | `AGENT_UNAVAILABLE` | 502 | 智能体不可达（含 4 类归因） |
| 3002 | `MCP_UNAVAILABLE` | 502 | MCP 不可达 |
| 3003 | `EGRESS_BLOCKED` | 502 | 出网被阻断（未走代理 / 缺根证书） |
| 3004 | `UPSTREAM_TIMEOUT` | 504 | 上游超时 |
| 1300 | `STATE_ILLEGAL` | 409 | 未签协议就提交/发布；死信状态不对时重试 |

## 4. 数据初始化

```
StartupInitializer.run()
  ① DatabaseBootstrap     建 23 张表（幂等）
  ② LibraryImportService  导入 375 个 Skill（空库才导）
  ③ DocSeedService        同步 6 篇在线文档
  ④ MsSeeder（新增）      逻辑库 default/staging · 4 个索引 · 5 条约束 · 3 个事件
                          · 9 条指标字典 · 2 个 Agent · 2 个 MCP   ← 全部幂等（先查后插）
```

要重灌：删 `data/db/`（H2）或 `DROP DATABASE`（MySQL）后重启。
