## 7. 已知限制与验证方式

| 限制 | 怎么验证 | 影响 |
| --- | --- | --- |
| 不做登录 | 把 `X-SKH-Role` 改成 admin 即可改库结构 | 不能当权限控制 |
| 索引是逻辑索引 | 「索引」页看条目；`EXPLAIN` 数据库仍是它自己的索引 | 不直接影响 DB 执行计划 |
| 查询台只读单表 | 试 `JOIN` → 409/2100 | 复杂分析要靠导出 |
| 事件动作进程内 | `NOTIFY` 只落日志 | 没有真正通知渠道 |
| 实测默认回退离线桩 | 断网跑一次，看徽标「离线兜底」 | 桩结果不代表真实模型表现 |
| 评估只用统计与最优化 | 看指标字典只有 9 项、无知识图谱入口 | 刻意边界 |
