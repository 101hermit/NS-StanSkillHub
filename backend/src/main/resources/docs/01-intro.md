# EasySkillHub 是什么

EasySkillHub（缩写 **ESKH**）是一个 **Skill 资源站**。

## 先用一句话说清 Skill

> **Skill = 一份写给 AI 的"工作手册"：一个文件夹 + 一份 `SKILL.md` 说明书。**

`SKILL.md` 的正文告诉 AI"遇到什么情况、按什么步骤做事"；
文件夹里的其它文件（脚本、模板、参考资料）是它的工具箱。
把这样一个文件夹放进 `~/.claude/skills`，你的 AI 助手就学会了这门手艺。

## 这个站点做什么

四件事，全部在页面上完成：

| 能力 | 在哪 | 说明 |
| --- | --- | --- |
| **找** | 「Skill 库」 | 375 个 Skill，按 15 个分类、6 个行业场景、5 档风险等级筛选 |
| **看** | 「详情页」 | 完整 SKILL.md、版本历史、附件清单、风险评估报告、源码直链 |
| **装** | 「详情页 → 安装」 | 下载 ZIP / 复制一条命令 / 跳到上游仓库 |
| **传** | 「在线贡献」 | 上传 SKILL.md，签协议，提交，评估并发布；分个人与部门两种身份 |

此外还有一个 **静态风险评估**：每个 Skill 都会被 32 条安全指标扫一遍，
给出 0-100 分与四档等级。它不联网、不调模型，结果可复现 —— 见 [安全评估](security)。

## 这个版本**不**做什么

边界比功能更重要。EasySkillHub 刻意不做下面这些：

- ❌ **不在线实测**：本站不连接任何智能体或大模型，所以**所有页面都不需要外网**，断网也能用。
- ❌ **不管理 Skill 库的结构**：没有"索引 / 约束 / 触发器"这类数据库语义 —— 那是标准版
  StanSkillHub 的事。
- ❌ **不做知识级分析**：知识图谱、语义检索、统计检验都不在本版本范围内 —— 那是专业版
  ProSkillHub 的事。
- ❌ **不做登录与权限**：本版用轻量身份上下文（请求头 `X-SKH-Actor` / `X-SKH-Role`），
  适合内网工具场景；生产接入 SSO 属于后续路线。

需要上面这些能力时，请直接换用对应的版本 —— 三个版本的界面与操作习惯是一致的，
技能库也是同一个。

## 三个版本的关系

```
EasySkillHub（资源站）  ⊂  StanSkillHub（+ 库语义 + 在线实测）  ⊂  ProSkillHub（+ 多维实验 + 知识级分析）
  端口 30800                     端口 30801                            端口 30802
```

## 数据从哪来

- 375 个 Skill 来自三份真实语料的**排他性合并**：openEuler SkillHub 镜像语料（129）、
  Skill 规范语料（194）、场景化语料（86）；同名/同内容的被合并，共 34 个。
- 合并后的库放在工程根的 `skills/` 目录，含 `catalog.json`（机器可读目录）与 `CATALOG.md`。
- 数据库只存"索引与关系"，库内容本身以文件为准 —— 换库、清库都不影响 Skill 本身。
