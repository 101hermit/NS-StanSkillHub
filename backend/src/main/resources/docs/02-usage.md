# 使用指南：找、看、装

## 1. 找：三种找法，从粗到细

### 1.1 按分类格子逛

首页和「Skill 库」页都是**格子窗**。15 个分类并排摆着：

- **工程类 8 个**：开发与构建、工程与编译、质量与校验、安全加固、性能优化、监控与运维、发布与部署、研究与设计
- **行业类 6 个**：教育、金融、政务与法务、医疗健康、新闻传媒、交通物流
- **兜底 1 个**：通用与其他

点一个分类就只剩这一类。行业类还会顺带确定「场景」。

### 1.2 按条件筛

「Skill 库」左侧是筛选器，可以叠加：

| 筛选项 | 可选值 | 什么时候用 |
| --- | --- | --- |
| 分类 | 15 类 | 我知道我要哪一类能力 |
| 场景 | 通用 / 教育 / 金融 / 政务 / 医疗 / 传媒 / 交通 | 我在某个行业里做事 |
| 风险等级 | 安全 / 低 / 中 / 高 / 未检测 | 我只想用安全的 |
| 贡献者类型 | 个人 / 部门 | 我想找某类人做的东西 |
| 来源 | 本地库 / GitHub / Gitee / GitLab / 在线上传 | 我想看来自某个平台的 |
| 状态 | 已发布 / 已归档 | 归档的默认不显示 |

排序有四种：最近更新（默认）、下载最多、风险最低、名称。

### 1.3 按关键词搜

顶部检索框输入关键词。打分规则（可解释，不是黑盒）：

| 命中位置 | 得分 |
| --- | --- |
| 名称 | 100 |
| 标题 | 60 |
| 描述 | 40 |
| 标签 | 30 |
| 正文 | 10 |

结果按总分从高到低。所以"名字里就带这个词"的永远排最前。

## 2. 看：详情页读什么

详情页是**两栏**：

**左栏 = SKILL.md 正文**。这是 Skill 的说明书本身，逐字原文，没有经过改写。

**右栏从上到下四张卡：**

1. **风险卡**：0-100 分的半环仪表 + 四档等级 + 一句话结论。
   想看 32 条指标明细就往下展开。
2. **安装卡**：三种安装方式，每种都是一键复制。
3. **版本卡**：每个版本的大小、说明、时间。可以点开看历史版本的原文。
4. **附件卡**：这个 Skill 目录里有哪些文件、各多大。带脚本的 Skill 会标出来。

页面底部还有「相关技能」—— 同分类里下载最多的 6 个。

## 3. 装：把 Skill 放到自己机器上

Skill 的"安装"其实就是**把一个文件夹放到 AI 助手会读的位置**。
Claude Code 系的约定位置是 `~/.claude/skills/<skill-name>/`。

三种方式任选：

### 方式 A：下载 ZIP（最稳）

点「下载 ZIP」→ 得到一个 `<name>.zip` → 解压 → 把里面的文件夹整个拖进 `~/.claude/skills`。

### 方式 B：复制一条命令（最快）

```bash
curl -fL -o /tmp/pdf.zip "http://<本站地址>/api/v1/skills/lib%3Apdf/download" \
  && mkdir -p ~/.claude/skills \
  && unzip -oq /tmp/pdf.zip -d ~/.claude/skills
```

> 注意：`skill_id` 里有冒号，所以命令里的地址是 URL 编码过的。前端会帮你编好，直接复制即可。

### 方式 C：源码直链（想审计就用这个）

跳到上游仓库看原文。支持 **GitHub / Gitee / GitLab** 三种链接格式。
如果你要把它改造成公司内部版本，从这里 fork 最省事。

## 4. 常见问题

**Q：下载下来是空的 / 只有一个 SKILL.md？**
A：说明这个 Skill 在库里只有说明书、没有附带脚本。这很正常 —— 很多 Skill 就是纯文字指引。

**Q：风险分很高，还能用吗？**
A：分数高代表"它要做的事很敏感"（比如会执行命令、会访问网络），不等于"它是恶意的"。
建议先在隔离环境试一次，确认它到底访问了什么。详见 [安全评估](security)。

**Q：为什么有的 Skill 显示「未检测」？**
A：它的评估记录缺失（例如刚通过接口导入、还没跑扫描）。点详情页的「重新评估」即可。

**Q：我可以直接改下载下来的 SKILL.md 吗？**
A：当然可以，改完就是你自己的版本了。如果你想把它交回站内，用「在线贡献」上传即可。
