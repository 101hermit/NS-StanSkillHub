# 术语小词典

站内出现的每一个专业词都在这里有解释。**任何页面第一次出现这些词时，都应该能点到对应解释。**

## Skill 相关

| 词 | 人话解释 |
| --- | --- |
| **Skill** | 一份写给 AI 的"工作手册"：一个文件夹 + 一份 `SKILL.md` 说明书。 |
| **SKILL.md** | Skill 的说明书本体。开头一小段 `key: value`（frontmatter）是元数据，下面是正文。 |
| **frontmatter** | `SKILL.md` 最上面被两行 `---` 夹住的那一段。里面写名称、描述、许可等。 |
| **description** | frontmatter 里的"什么时候该用我"。**这一句决定了 AI 会不会想起你**。 |
| **Skill 库** | 所有 Skill 放一起的地方，可以搜索、下载、贡献。本站有 375 个。 |
| **slug** | Skill 的短名字（小写 + 连字符），也是它在库里的目录名。 |
| **skill_id** | Skill 的稳定身份。三种形态：`lib:<slug>`（库里的）、`<平台>:owner/repo/name`（有源码直链的）、`local:贡献者/名称`（纯上传的）。 |
| **版本快照** | 每次发布/编辑都会存一份当时的正文，可以回溯。 |
| **bundle** | 贡献时可选带的 ZIP，装 Skill 需要的脚本与参考资料。 |

## 贡献与分发

| 词 | 人话解释 |
| --- | --- |
| **贡献四步** | 上传 → 签协议 → 提交 → 评估发布。 |
| **CLA** | 贡献者协议。填个名字即完成，记录签名人与时间。 |
| **个人 / 部门** | 两种创作者身份，只影响归类与署名，不影响流程。 |
| **分发** | 把 Skill 文件夹送到别人磁盘上。三种方式：下载 ZIP、复制命令、源码直链。 |
| **源码直链** | 指向上游仓库（GitHub / Gitee / GitLab）的地址。 |
| **软删（归档）** | 从列表里撤下但数据还在，随时可恢复。物理删除需要管理员。 |

## 风险评估

| 词 | 人话解释 |
| --- | --- |
| **风险分** | 0-100 的分数。命中指标的权重累加，封顶 100。 |
| **风险等级** | 四档：安全（0-20）/ 低（21-50）/ 中（51-80）/ 高（81-100）。 |
| **维度** | 风险的六个大类：提示注入、数据外泄、权限与代码执行、供应链、系统提示与记忆、危险代码。 |
| **指标** | 维度下面的一条具体规则，例如"远程下载并执行"。共 32 条。 |
| **信号** | 一次评估里命中的具体位置（哪条指标、哪个文件的第几行）。 |
| **remediation** | 修复建议。照着改就能降分。 |
| **确定性扫描** | 同一份文本永远得到同一个结果 —— 因为它是规则匹配，不是大模型判断。 |

## 通用

| 词 | 人话解释 |
| --- | --- |
| **分类** | 15 个格子：8 个工程类 + 6 个行业类 + 1 个兜底。 |
| **场景** | 行业维度：通用 / 教育 / 金融 / 政务 / 医疗 / 传媒 / 交通。工程类分类的场景固定是"通用"。 |
| **格子窗** | 卡片网格布局。宽屏 4 列、中屏 3 列、窄屏 1 列，永远不出现横向滚动。 |
| **追踪号（trace_id）** | 一次请求的 8 位编号。报障时提供它，管理员能 grep 出这次请求的全部日志。 |
| **身份头** | 请求头 `X-SKH-Actor` 与 `X-SKH-Role`。本版不做登录，用它表示"谁在操作"。 |

## 只在本系列其它版本出现的词

下面这些词在 EasySkillHub 里**不会出现**，列在这里是为了让你换版本时不陌生：

| 词 | 出现在 | 人话解释 |
| --- | --- | --- |
| **逻辑库（Skillset）** | 标准版 / 专业版 | Skill 的"分类抽屉"，类似数据库里的一个 database。 |
| **索引** | 标准版 / 专业版 | 给 Skill 的某个属性建一个"目录页"，查起来更快。 |
| **约束** | 标准版 / 专业版 | 一条"不许违反的规矩"，比如"风险分不能超过 80"。 |
| **事件（触发器）** | 标准版 / 专业版 | 一件事发生后自动做另一件事，比如"新增 Skill 就自动打标签"。 |
| **在线实测** | 标准版 / 专业版 | 真的把 Skill 挂到一个智能体上跑一次，看它答得怎么样。 |
| **推理过程** | 标准版 / 专业版 | 智能体在给出答案前，先说了它打算怎么做。 |
| **任务效能** | 专业版 | 答得对不对、全不全、稳不稳。 |
| **通信性能** | 专业版 | 快不快：多久出第一个字、总共多久、花了多少字。 |
| **超参数** | 标准版 / 专业版 | 影响模型"性格"的旋钮，比如"发散程度（temperature）"。 |
| **MCP** | 标准版 / 专业版 | 让智能体能调用外部工具的一套标准接口（相当于给 AI 装上"手"）。 |
| **知识图谱** | 专业版 | 把 Skill、场景、能力画成一张"关系网"，看看谁和谁有关。 |
